# URL-Shorten
[![Powered by Poetry](https://img.shields.io/badge/Powered%20by-Poetry-060b55.svg?style=flat&logo=python&logoColor=white)](https://python-poetry.org/)

A simple and lightweight URL shortener built with Python.

## Screenshot
![Screenshot of the app](https://github.com/KarthikUdyawar/URL-Shorten/blob/main/images/Screenshot.png)

## Features
- Shorten long URLs easily
- Clean and minimal UI
- Easy to run locally

## Requirements

- Python 3.8+
- Poetry

> You can install Poetry by following the [official guide](https://python-poetry.org/docs/#installation).

## Setup & Installation

Make sure you have the latest version of **Python** and **Poetry** installed.

Clone the repository:

```bash
git clone https://github.com/KarthikUdyawar/URL-Shorten
cd URL-Shorten
```

Install dependencies:

```bash
poetry install
poetry env activate
```

## Running the App

Start the application:

```bash
poetry run python main.py
```
